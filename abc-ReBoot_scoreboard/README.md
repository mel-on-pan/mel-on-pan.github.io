# クイズ大会スコア＆問題表示システム

仕様は `docs/` を参照。ビルド不要の HTML / CSS / Vanilla JS 構成。

| 画面 | ファイル | 用途 |
|---|---|---|
| 運営パネル | `index.html` | 問題送り・正誤判定・加減点・Undo・設定 |
| スコアボード | `screen.html` | プロジェクター表示 (運営パネルの「スコアボードを開く」から) |
| 観客ビューア | `viewer.html` | 観客スマホ。QRコードから開く |

## 使い方

1. **公開する** (観客スマホ接続に必須)
   フォルダ一式を GitHub Pages などの HTTPS ホスティングに置き、`https://…/index.html` を運営PCの Chrome / Edge で開く。
   (ローカルで `index.html` を直接開いても運営・スコアボードは動きます。その場合は 設定 > 観客用スマホ接続 に公開先URLを入力)
2. **スコアボードを開く** → 別ウィンドウをプロジェクター側へ移動し、`F` キーまたはダブルクリックで全画面。
3. **設定** でルール (`N○M×` / `NbyN` / フリー、誤答休み)、プレイヤー名・色を入力。
4. 観客にはパネル右上のQRコードを読んでもらう (「スコアボードにQRを表示」で投影も可)。

### 操作

| 操作 | ボタン | キー |
|---|---|---|
| 次の問題へ (正解は伏せた状態) | 次の問題 | `N` |
| 誰も正解しなかった → 正解を公開 | スルー | `T` |
| 正解を公開 | 正解表示 | `A` |
| 直前の操作を取り消す (最大100回) | 元に戻す | `Ctrl+Z` |

- 各プレイヤーの「○ 正解」「× 誤答」で判定。勝ち抜け・失格は自動判定され、順位 (1st, 2nd…) が付きます。
- 「○±1」「×±1」は手動補正用。
- 途中経過は localStorage に自動保存され、リロードしても復元されます。

## 問題データ

`questions.json` (同じフォルダ) を起動時に自動読込。ローカルで直接開いた場合は 設定 > 問題データ からファイルを選択。

```json
[{ "id": 1, "question": "問題文", "answer": "正解", "explanation": "解説 (省略可)" }]
```

## 効果音

`sounds/README.md` を参照。ファイルが無い場合は合成音で鳴ります。

## 通信について

- 運営パネル ⇔ スコアボード: `BroadcastChannel` (+ localStorage)。インターネット不要。
- 運営パネル ⇔ 観客スマホ: PeerJS (WebRTC)。PeerJS の無料公開サーバーを利用するためインターネット必須。
  - 目安は数十人〜100人程度。モバイル回線などでは一部の端末が接続できない場合があります。
  - 運営パネルのタブを閉じる・PCがスリープすると観客の接続が切れます (復帰後、自動で再接続)。
  - 接続IDはブラウザに保存されるため、リロードしても同じQRコードが使えます。
