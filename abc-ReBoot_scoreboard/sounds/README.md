# 効果音ファイル

このフォルダに以下の名前で mp3 を置くと、運営パネル (index.html) で自動的に再生されます。
ファイルが無いものは、ブラウザで生成した合成音で代用されます。

| ファイル名 | 鳴るタイミング |
|---|---|
| `correct.mp3` | 正解 (○) |
| `wrong.mp3` | 誤答 (×) |
| `win.mp3` | 勝ち抜け確定 |
| `lose.mp3` | 失格確定 |
| `question.mp3` | 次の問題 |
| `reveal.mp3` | 正解表示 |
| `through.mp3` | スルー |

※ 音は運営パネルのタブから鳴ります (スコアボード画面からは鳴りません)。会場スピーカーには運営PCの音声出力をつないでください。
